**Strengthening LLM Trust Boundaries: A Survey of Prompt Injection Attacks**
强化LLM信任边界：提示词注入攻击综述。

---

### 1. 这篇论文说的 Problem 是什么？

论文的核心研究对象是**大语言模型（LLM）的提示词注入攻击（Prompt Injection, PI）**。其聚焦的具体问题包括：

* **对齐机制的局限性与天然漏洞：** 目前主流的 LLM 对齐工具（如 RLHF 和系统提示词 System Prompts）均无法提供限制 LLM 的严格规则。RLHF 容易在面对未见过的输入时表现出不可预测性，系统提示词也仅仅是概率性地引导响应。两者的 gap（空隙）为恶意攻击者留下了可利用的攻击面。
* **信任边界的失效：** 在包含外部工具的复杂 LLM 应用中，开发者隐含的两个“信任边界”容易被攻破：
** **TB1（信任边界1）：** 预期系统提示词能维持模型对齐。该边界常被“直接攻击”（如越狱）绕过。
** **TB2（信任边界2）：** 预期外部支持系统（如 Python 解释器、浏览器）输入输出的数据不会使模型失调。该边界常被“间接攻击”剥夺。


* **现有防御的滞后性：** 目前的缓解策略缺乏原则性，主要是在某些攻击流行后进行“头痛医头”的被动补丁，无法从根本上解决跨越信任边界的整类攻击。

### 2. 论文用的 Method 是什么？

作为一篇综述性质的论文，作者通过以下方法建立了系统化的分析框架：

* **定义“提示词注入空间（Prompt Injection Space）”模型：** 将提示词处理和攻击机会由大到小、由疏到密划分为五个层次：**嵌入空间（Embedding space）、标记空间（Token space）、词语空间（Word space）、句子空间（Sentence space）** 以及 **已探索空间（Explored space）**。
* **建立双重信任边界威胁模型（Trust Boundary Framework）：** 绘制了 LLM 系统的攻防拓扑图，明确区分了针对 TB1 的**直接攻击（Direct Attacks）**和针对 TB2 的**间接攻击（Indirect Attacks）**。
* **严格的文献纳入标准：** 明确**只包含有记录且证实成功攻击了至少一个商用或开源 LLM 的案例**，确保研究聚焦于现实世界中的实质性威胁。
* **能力与空间映射（Expertise Mapping）：** 建立矩阵（Table II），将不同技术背景的攻击者（新手、中级、专家、超级专家）与他们在不同提示词空间中进行“手工构建（Handcrafting）”或“算法优化（Optimization）”的能力进行量化映射。

### 3. 论文的 Advantage 是什么？

* **结构化与条理性极强：** 论文没有胡乱堆砌攻击案例，而是首次引入了“五个空间维度”和“两大信任边界”，将极其混乱的提示词注入攻击进行了清晰的定性归类。
* **揭示了技术门槛与攻击空间的内在联系：** 明确指出低维空间（如句子空间）易于人类手工构建攻击，但难以进行算法优化；高维空间（如嵌入空间、标记空间）虽然对人类不可读、对新手门槛极高，但它表现出的平滑性非常适合利用机器学习算法（如遗传算法、贪婪搜索）实现自动化的“通用越狱”。
* **前瞻性地关注间接攻击（IA）：** 敏锐地指出随着 LLM 越来越多地承担“编排器（Orchestration）”并调用外部工具，间接攻击的威胁正在成正比例上升，为下一代安全防范指明了方向。

### 4. 论文提到的 Limitation 是什么？

* **缺乏可量化的最优防御技术：** 论文指出目前的对齐和防御研究过于狭隘地关注“模型对越狱的抗性”，在加强信任边界的同时，会带来怎样的性能牺牲（可量化的权衡/Trade-offs）目前完全未知，行业内缺乏帕累托最优（Pareto optimal）的对齐防卫技术。
* **评估手段原始：** 现阶段判断 LLM 是否遭到注入攻击并泄露隐私，主要的防御和检测手段依然依赖于**基础的字符串匹配（Basic string matching）**，这在面对复合型、复杂的安全突破时基本失效。
* **未提供普适性的防御终极方案：** 论文诚实地总结道，截至目前，**依然没有任何一种泛化（Generalizable）的、符合安全原则的方法**能够彻底解决提示词注入问题。

### 5. 论文给出的 Inspiration 是什么？

论文在结论部分为未来的大模型安全研究指明了 7 个极具启发性的具体演进方向：

1. **基准测试对齐技术：** 需定义最优性指标，寻找攻防平衡的帕累托最优对齐技术。
2. **构建 alignment 失败的度量指标：** 开发超越简单字符串匹配的、更清晰明了的指标，用以评估复杂任务下的泄露程度并预测未来的安全破口。
3. **建立专用的注入攻击数据集：** 汇编广泛的提示词注入失败案例数据集，通过构建攻击者模型来提前预测漏洞。
4. **探索人类可读提示词的优化：** 研究如何在保持人类可读性的前提下对句子空间提示词进行算法优化，以防范极具耐心的非技术人员逐渐摸索出新型越狱词。
5. **序列时序分析：** 探索是否可以通过分析用户多轮对话查询的时序动态特征（Temporal dynamics），在安全崩溃发生前提前预测并拦截。
6. **对齐技术的迁移性研究：** 评估用于保护某一 LLM 信任边界的防御技术，是否能快速部署和通用到其他不同架构的模型上。
7. **事后溯源分析（Post-hoc analysis）：** 发展大模型被攻破后的“尸检”技术，以理解其深层成因（包括社会技术层面的原因）。

## 💡 论文中其他需要您了解的重要信息

除了上述回答，论文中还有几个非常有趣且关键的技术细节和事实，您在理解大模型安全时需要特别注意：

* **越狱攻击的演进史与典型变体：**
论文详细梳理了已经被商业模型通过补丁（Patches）封堵、但在安全研究中具有里程碑意义的几类句子空间直接攻击（DAs）：
* **DAN (Do Anything Now):** 早期最具代表性的越狱，通过社群分布式地迭代手工构建，不断与 OpenAI 的补丁周期赛跑。
* **角色扮演变体（Roleplay variations）:** 让 LLM 模拟恶意黑客、甚至模拟“给孙女讲睡前故事的善良奶奶”，核心在于彻底破坏 LLM 区分善恶场景的能力。
* **混淆攻击（Obfuscation）:** 利用 LLM 预训练中常见的 `<mask>` 标记，诱导大模型在内部自行还原并生成被安全过滤器过滤的敏感词。
* **负载分裂（Payload Splitting）:** 将恶意词汇拆分（例如将 "steal" 拆为 "ste" 和 "al" 赋值给变量），让单个词通过过滤器，最终在模型内部拼接执行。
* **发散攻击（Divergence attacks）:** 通过诱导 LLM 连续不断地重复某一个标记，模拟训练数据结束的特殊标记 `<endoftext>`，从而导致模型发生严重故障并**大段泄露其底层的底层训练数据**。


* **“令牌走私”攻击（Token Smuggling）：**
这是一种结合了直接攻击和间接工具调用的新型间接攻击手法。攻击者利用句子空间提示词诱导 LLM，让其调用 **Python 解释器工具**，通过简单的字符串拼接函数（String concatenation）在解释器内部重组恶意提示词（例如拼接出“如何抢银行”），然后让 LLM 扮演另一个大模型继续基于该重组结果进行生成，从而完美绕过前置的安全审查。
* **黑盒与白盒模型的安全差距：**
在本地托管的“白盒模型”（如 Llama）中，用户拥有完整的嵌入和中间对数几率（logits）访问权，因此专家可以使用机器学习算法平滑地优化出近乎完美的攻击提示词；但可怕的是，论文指出这些在开源白盒模型上被算法优化出来的“通用对抗标记序列”（如 Zou 等人发现的看似乱码的 Token 组合），**可以直接成功迁移（Transfer）到像 ChatGPT 这样的闭源黑盒模型上**，这使得闭源模型的“安全护城河”变得极为脆弱。
